## 📌 About Project
**Tatib SMK Wiraguna** adalah aplikasi web interaktif yang dirancang khusus untuk mengelola tata tertib, catatan prestasi, dan pelanggaran siswa secara digital. Mengusung konsep *Gamification* ala game RPG (Role-Playing Game), sistem ini memvisualisasikan kedisiplinan siswa ke dalam bentuk **Health Point (HP)**, **Shield Point**, serta status penanganan yang dinamis untuk menciptakan pengalaman monitoring yang transparan dan menarik.

---

## ✨ Core Features

*   **🛡️ RPG Character Status Portal (Siswa):**
    *   Cek status kedisiplinan secara *real-time* menggunakan Nomor NIS / NISN.
    *   Visualisasi bar *Health Point* (HP) dan *Shield Point* layaknya game klasik.
    *   Sistem gelar/badge khusus otomatis (seperti *The Night Owl*, *Perfect Defender*, dll).
*   **👨‍🏫 Teacher & Staff Portal (Petugas/Guru):**
    *   Pencatatan input poin prestasi atau pelanggaran secara terstruktur (berdasarkan hari, tanggal, jam, lokasi, dan kategori).
    *   Dukungan mode input **Satu Siswa** maupun **Banyak Siswa sekaligus (Multi-select)**.
*   **👑 Super Admin Control Panel:**
    *   Rekapitulasi data siswa lengkap dengan filter kelas (10 SMK, 11 SMK, 12 SMK).
    *   Panel kontrol tindakan khusus (Reset poin penuh, penambahan/pengurangan HP, dan catatan sidang BK).
    *   Fitur ekspor & cetak laporan rekapitulasi dokumen.
*   **📜 Quest Board (Buku Tatib Digital):**
    *   Panduan interaktif berbasis kategori/tingkat (Ringan, Sedang, Berat) untuk daftar pelanggaran beserta sanksinya, dan rincian poin prestasi.
*   **🎮 Easter Eggs System:**
    *   Fitur interaktif tersembunyi bagi pengguna yang mengeksplorasi sistem lebih dalam.

## 🛠️ Tech Stack

*   **Frontend:** HTML5, CSS3 (Custom Glassmorphism & Responsive Flex/Grid), Vanilla JavaScript (ES6+).
*   **UI/UX Styling:** Google Fonts (*Poppins*), CSS Animations, Custom Preloader Screen.
*   **Storage / Database:** Mock State Management (Ready to integrate with Google Apps Script / Google Sheets API).
